# To-Do List Application

A simple command-line To-Do List Application built using Python.

## Features

- Add Tasks
- View Tasks
- Delete Tasks
- Menu-Based Interface

## Technologies Used

- Python

## Concepts Used

- Lists
- While Loops
- Conditional Statements (if-elif-else)
- User Input

## How to Run

1. Download or clone the repository.

2. Open the project folder.

3. Run the program:

```bash
python main.py
```


## Sample Menu

```text
===== TO-DO LIST =====

1. Add Task
2. View Tasks
3. Delete Task
4. Exit
```
